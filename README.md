# Phone Directory Management System

A simple console-based Python application for managing a phone directory with admin controls and data validation.

## Features

* **Admin Dashboard:** Secure login system with username and password verification.
* **Add Phone Number:** Add new contacts with validation for phone numbers (must be 10 digits starting with `059`) and IDs (must be exactly 9 digits).
* **Show All Records:** View all stored phone numbers and contact details.
* **Search Functionality:** Search for contact details using a specific phone number.
* **Update Records:** Modify existing contact information based on the phone number.
* **Delete Records:** Remove contacts from the directory.

## Project Structure

The project is written in pure Python and uses basic data structures (lists and dictionaries) to handle CRUD operations dynamically during runtime.
